# PBT5 sanitizer 영향 비교

## 1. 같은 응답에서 정리기만 적용

- 채점기가 실제로 읽는 코드가 정리 전후 완전히 일치: 100/100
- 정리기 복구 모델 호출: 0회; 추가 기록 비용 $0.000000
- 정리 전 통과: 46/100
- 정리 후 통과: 46/100
- 둘 다 통과 46, 정리 전만 통과 0, 정리 후만 통과 0, 둘 다 실패 54
- 같은 GPT 응답과 가상 사용자 답변을 사용했다. 코드 실행의 환경이나 비결정성은 별도의 요인이 될 수 있다.

## 2. 독립 실행 비교

- 이전 PBT5: 51/100; 새 PBT5_1: 46/100
- 둘 다 통과 42, 이전만 통과 9, 새 실행만 통과 4, 둘 다 실패 45
- 독립 실행이어서 속성 판정, 질문, 사용자 응답과 코드가 달라질 수 있다. 점수 차이를 sanitizer 때문이라고 결론 낼 수 없다.
- PBT5_1은 PBT5 실험 스냅샷을 기준으로 정리기만 제거했다. sanitizer 설정과 호출을 제외한 run() AST는 동일함을 확인했다.
